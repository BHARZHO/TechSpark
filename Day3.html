Part 1 • Core Concept

💻 What is HTML?

📝 Notebook Definition
HTML = HyperText Markup Language

🔹 HyperText

Text that connects to another webpage using clickable links (like links on Google or YouTube!).

🔹 Markup

Using tags like <h1>Welcome</h1> to tell the browser what each piece of content is.

🔹 Language

The special language that web browsers understand to show text, pictures, and buttons on screen.

Technology Analogy in a House 🏠 What It Does on a Webpage

Part 3 • Tag Anatomy

🏷️ What is an HTML Tag?

👨‍🏫 Tag Anatomy Breakdown

Look carefully at this example tag:

<h1>Hello</h1>
  • 🟢 Opening Tag (<h1>): Tells browser "Start a Heading".
  • 💬 Content (Hello): The text shown on the webpage.
  • 🔴 Closing Tag (</h1>): Notice the slash /! Tells browser "Heading ends here".
📝 Notebook Golden Rule

✍️ Copy this formula:

<tag>Content</tag>

Paragraph Example:
<p>I love coding.</p>

Part 9 • Classroom Quiz

🧠 Quick Quiz: Test Your Knowledge!

Click any card to reveal the answer!

1. What does HTML stand for?
HyperText Markup Language
2. What is the job of HTML?
To build the structure of a webpage
3. What is a tag?
A keyword wrapped in angle brackets like <h1> that tells the browser what content is.
4. Which tag creates a heading?
<h1> (or <h2>, <h3>, etc.)
5. Which tag writes a paragraph?
<p>
6. What appears in browser tab?
The text inside the <title> tag!
7. Visible part: <head> or <body>?
<body> is the visible part of the webpage!
8. Opening vs Closing tag?
A closing tag has a forward slash / like </h1>!
