Part 2 • What is CSS?

🎨 What is CSS?

💡 CSS stands for Cascading Style Sheets. CSS gives a webpage its appearance and design!

With CSS, we can control and change:

  • 🎨 Colors: Text, headers, and links.
  • 🖼️ Backgrounds: Page colors & card backgrounds.
  • 🔤 Fonts: Arial, Georgia, Verdana.
  • 📏 Sizes: Pixels (e.g. 18px, 32px).
  • 📦 Borders: Thickness, style, and colors.
  • ⭕ Rounded Corners: `border-radius: 10px`.
  • ↔️ Spacing: `padding` inside boxes.
  • 📍 Alignment: Left, center, or right.
Part 3 • CSS Rules

🧠 How Does CSS Work?

👨‍🏫 Click any part of the CSS rule below:
h1 { color : blue ; }

1. SELECTOR (h1)

Tells CSS: "I want to style the <h1> element."

Rule Pattern:

selector { property: value; }

Part 4 • Linking CSS

🔗 Connecting HTML and CSS

We keep HTML in `index.html` (structure) and CSS in `style.css` (design). We connect them inside the <head> tag!

📁 Project Files
📁 My Website │ ├── index.html │ └── style.css
<link> Tag in HTML
<head> <title>My Profile</title> <link rel="stylesheet" href="style.css"> </head>

Part 8 • Cheat Sheet

🧠 Today's CSS Cheat Sheet

CSS Property What It Does Example Code
color Changes text color color: blue;
background-color Changes background color background-color: lightblue;
font-size Changes text size font-size: 18px;
font-family Changes the text font font-family: Arial;
text-align Aligns text (left, center, right) text-align: center;
border Adds a border boundary border: 2px solid black;
border-radius Makes box corners rounded border-radius: 10px;
padding Adds space INSIDE a box padding: 20px;
