Part 4 • Hands-On Step 1

1️⃣ How to Open VS Code

🖥️ Option A: Desktop

Look on your desktop screen for the blue ribbon icon labeled Visual Studio Code and double-click it!

🔍 Option B: Search Bar

Press the Windows Key on your keyboard, type VS Code, and press Enter ↵.

Part 4 • Hands-On Step 2

2️⃣ Creating Your Project Folder

⚠️ Golden Rule

Every website project needs its own folder to stay organized. Never save random files loosely on your Desktop!

✍️ Practical Steps
  1. Go to your Desktop.
  2. Right-click on an empty space.
  3. Select New ➡️ Folder.
  4. Name your folder: MyFirstWebsite
📂 Opening Folder in VS Code

Inside VS Code, click File ➡️ Open Folder... then choose your MyFirstWebsite folder!

Part 4 • Hands-On Step 3

3️⃣ Creating Your First File

✍️ Step-by-Step Instructions
  1. In VS Code Explorer sidebar, click the New File icon 📄+.
  2. Type the exact file name: index.html
  3. Press Enter ↵ to create it!

📝 Notebook Rule

  • Why index.html? Web browsers automatically look for index.html first when loading any website homepage!
Part 5 • Essential Skill

💾 How to Save Your Work

🚨 Important Developer Habit

If you see a white dot ● next to your file name in VS Code, it means your work is UNSAVED!

Action Keyboard Shortcut What it Does
Save File Ctrl + S Saves your code changes immediately. Dot turns to ✕!
Undo Mistake Ctrl + Z Takes back your last action if you make a mistake.
Select All Ctrl + A Highlights all text in your file.
Part 6 • Seeing Results

🌐 Opening Your File in a Browser

🔹 Method 1: Double Click

Open your MyFirstWebsite folder in Windows Explorer and double-click index.html!

🔹 Method 2: Live Server

Right-click inside VS Code editor window and click "Open with Live Server"!
