Part 5 • Hands-On Step 1

📁 Creating Your First Project Folder

💻 Practical Exercise

Follow these 4 steps:

  1. 1️⃣ Go to your computer Desktop.
  2. 2️⃣ Right-click on an empty spot.
  3. 3️⃣ Select New ➔ Folder.
  4. 4️⃣ Type the name: HTML-Class
📝 Notebook Note

✍️ Why do we create project folders?

  • Keeps our work organized.
  • Helps us find files quickly.
  • Prevents losing our coding projects.
Part 6 • Hands-On Step 2

📄 Creating Your First HTML File

💻 Practical Exercise

Inside your HTML-Class folder in VS Code, click New File and name it:

index.html
✍️ Students, write this down!
⚠️ Press Ctrl + S to SAVE your file! Always save your work frequently!

🤔 Quick Questions:

Why "index"?

index.html is the standard main starting page of any website.

Why ".html"?

The extension .html tells the browser that this file is a web page!

Part 7 • Hands-On Step 3

🌐 Opening Your Web Page

💻 Method 1

Double Click

Go to your HTML-Class folder on Desktop and double-click index.html. It opens right in Google Chrome or Edge!

💻 Method 2

Open With Browser

Right-click index.html ➔ select Open With ➔ pick your web browser!

⚡ Pro Tip: Live Server

We can install an extension called Live Server in VS Code to auto-refresh our webpage every time we save!

Part 8 & 9 • Programmer Power-Ups

⌨️ Keyboard Shortcuts & Good Habits

📝 Good Coding Habits
  • ✅ Save your work often (Ctrl+S).
  • ✅ Give files clear names (like index.html).
  • ✅ Keep all project files inside one folder.
  • ✅ Read error messages carefully.
  • ✅ Practice coding every single day!
✍️ Useful Shortcuts

Ctrl + CCopy Text
