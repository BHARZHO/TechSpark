Part 2 • Environment

💻 VS Code, Files & Folders

👨‍🏫 What is VS Code?

VS Code is a code editor. We use it to write, organize, and edit our code!

📁 File vs Folder

📄 FILE

Stores information/code inside it.
Examples: index.html, style.css, script.js

📂 FOLDER

Organizes multiple files in one container.
Example: My Website/ project directory.

Part 3 • HTML Core

🟠 What is HTML & Basic Structure

HTML = HyperText Markup Language 🧱
HTML gives a webpage its STRUCTURE (like the walls & frame of a house)!
📝 HTML Skeleton Boilerplate
<!DOCTYPE html>
<html>
  <head>
    <title>My Website</title>
  </head>
  <body>
    <h1>Hello World!</h1>
  </body>
</html>

🏷️ Tag Checklist We Know

<h1> - <h6> <p> <a> <img> <ul> <ol> <li> <table> <form> <div>
Part 3 • Basic Elements

🔤 Headings, Paragraphs, Links & Images

🔤 Headings & Paragraphs

Headings range from <h1> (biggest) down to <h6> (smallest).

<h1>Heading 1 (Biggest)</h1>
<p>My name is Abdul and I am learning web dev.</p>
❓ Quiz: Which heading is the biggest? Answer: <h1>

🔗 Links & 🖼️ Images

<!-- Hyperlink -->
<a href="https://google.com">Visit Google</a>

<!-- Image -->
<img src="myphoto.jpg" alt="My picture">
  • href = Destination URL for links
  • src = Image file source | alt = Description
Part 4 • Lists

📋 Unordered (<ul>) vs Ordered (<ol>) Lists

• Unordered List (<ul>)

Used when order doesn't matter (bullets).

<ul>
  <li>Rice</li>
  <li>Chicken</li>
  <li>Fish</li>
</ul>

1. Ordered List (<ol>)

Used when step-by-step order matters (numbers).

<ol>
  <li>Wake up</li>
  <li>Brush my teeth</li>
  <li>Go to school</li>
</ol>
Part 5 • Data Tables

📊 Organizing Information with Tables

📝 HTML Table Code
<table border="1">
  <tr>
    <th>Name</th><th>Age</th><th>Class</th>
  </tr>
  <tr>
    <td>John</td><td>12</td><td>JSS 1</td>
  </tr>
</table>

🏷️ Table Tags Quick Guide

  • <table> → Creates the table wrapper
  • <tr> → Table Row (horizontal row)
  • <th> → Table Heading (bold header cell)
  • <td> → Table Data (standard cell)
Part 6 • User Inputs

📝 Interactive HTML Forms

📝 HTML Form Code
<form>
  <label>Name:</label>
  <input type="text">

  <label>Email:</label>
  <input type="email">

  <button>Submit</button>
</form>

🎯 Purpose of a Form

A form allows users to enter and submit information (like logging in, registering, or sending messages!).

Part 7 • Container Boxes

📦 Grouping Elements with <div>

Think of a <div> like a BOX 📦! We use it to group related elements together.

Part 8 • CSS Core

🎨 What is CSS? (Cascading Style Sheets)

HTML asks: "What content is on the page?" 🧱
CSS asks: "How should it LOOK?" 🎨

🔤 1. TEXT STYLING

color: blue;
font-size: 20px;

🎨 2. BACKGROUNDS

background-color: yellow;

📏 3. SPACING

margin: 20px;
padding: 20px;
Part 8 • CSS Selectors

🎯 CSS Selectors: Element, Class & ID

1. Element Selector

h1 { color: blue; }

Styles all <h1> headings on the page.

2. Class Selector (Starts with .)

.welcome { color: green; }

HTML: class="welcome"

3. ID Selector (Starts with #)

#title { color: red; }

HTML: id="title"

⚡ Quick Test: What does text-align: center; do?
👉 Answer: It moves text to the CENTER!
Part 8 • Box Model

📦 The CSS Box Model

MARGIN (Space outside border)
BORDER (Edge around element)
PADDING (Space inside border)
CONTENT (Text / Image inside)

🤝 How HTML & CSS Work Together

<!-- HTML creates structure -->
<h1>My Website</h1>

/* CSS styles structure */
h1 {
  color: blue;
  text-align: center;
}
HTML + CSS = Structured & Styled Webpage! 🚀
