Part 2 • Container Box

📦 What is a <div>?

📝 Container Definition

A <div> is a general-purpose HTML container / box.

<div> = BOX / CONTAINER

Its main job is to group elements together and help you organize your webpage structure.

Part 3 • Container Nesting

📦📦 Box Inside Box (Nesting)

📝 Nesting Rule
Nesting means: Putting one HTML element inside another HTML element.

💻 Code View

<div class="website"> <h1>My Website</h1> <div class="about"> <h2>About Me</h2> <p>I am learning web development.</p> </div> </div>

Part 9 • Quick Quiz

🧠 Advanced Classroom Quiz

Click any card to reveal the answer:

1. What does <div> mean?
Division / General-purpose HTML container box.
2. Does <div> automatically style a page?
No! Its main job is organizing structure. CSS handles styling.
3. What is nesting?
Placing one HTML container/element inside another.
4. Why do we use `class`?
To give container boxes names so we can target them with CSS.
5. What container wraps the whole layout?
The outer main box (e.g. <div class="website">).
6. What goes inside .header?
Header content like titles (<h1>) or branding logos.
7. How do you write a class selector in CSS?
With a dot prefix like .header { ... } or .skills { ... }.
8. Must every <div> have a closing </div>?
Yes! Every opening <div> must have a matching closing </div>.
