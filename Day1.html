Part 4 • Comparison

⚙️ Website vs Web Application

📄 Website (Informational)

Mainly provides information for you to read, watch, or look around.

🏫 School Website 📰 News Site 📝 Personal Blog

⚡ Web Application (Interactive)

Allows you to do tasks: send messages, upload photos, buy products, or edit docs.

💬 WhatsApp Web 📷 Instagram 📄 Google Docs

🤔 Quick Classroom Test!

Q1: Can you send a WhatsApp message on a normal school website?
Q2: Can you send a message using WhatsApp Web?

Part 6 • The Big Three

🏠 Meet HTML, CSS & JavaScript

🧱 HTML → STRUCTURE

Builds the walls, rooms, doors and text sections of the website.

🎨 CSS → DESIGN

Adds colors, paint, styling, layout, sizes and beautiful fonts.

⚡ JavaScript → FUNCTIONALITY

Makes things work: doors open, lights turn on, buttons click!
