Part 1 • Tables Concept

📊 What is a Table?

👨‍🏫 Click any tag line below to inspect its role in the table:
<table border="1">   <tr>     <th>Name</th><th>Age</th><th>Class</th>   </tr>   <tr>     <td>John</td><td>15</td><td>SS2</td>   </tr> </table>

<table> Element

Tells the browser: "Start making a data table here!"

✍️ Memory Rule:

TABLE ➔ ROW (tr) ➔ HEADING (th) ➔ DATA (td)

Part 4 • Form Tags

🏷️ Form Elements & Input Types

📝 Core Form Tags
  • 📦 <form> ➔ Outer container for the form.
  • 🏷️ <label> ➔ Text label telling the user what to type.
  • ⌨️ <input> ➔ The typing box where users enter data.
  • 🔘 <button> ➔ Clickable button to submit information.
💡 Key Input Types
  • 🔤 type="text" ➔ Normal text (e.g. Abdul, David).
  • 📧 type="email" ➔ Email address (student@gmail.com).
  • 🔢 type="number" ➔ Numeric values (e.g. 15).
